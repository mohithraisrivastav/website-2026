AR GLB Builder — GOAF Fine Art Prints

Generates the 27 missing per-size GLB files (Small · Medium · Large) for all 9 products.
Standard-size GLBs already live in ar/ — this tool only builds the three additional sizes.

How to use: Open this page from your local server (e.g. npx serve . inside the project root) so it can load images from the images/ folder, then click Generate All. Each GLB is downloaded automatically as it finishes. Move all downloaded files into the ar/ directory and deploy. Name format: ar/{product-id}-{size}.glb — exactly what the AR sheet expects.
